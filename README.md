# 🩸 Blood Donation Website

## 👨‍💻 Developed By

**Kshitiz Tiwari**

**Prashant Dubey**


A web-based **Blood Donation Website** developed using **Python Flask and MySQL** to manage blood donors, campaigns, and blood stock efficiently.

The system allows users to register, participate in blood donation campaigns, and enables administrators to manage donors, campaigns, and blood stock through an admin dashboard.

---

## 🚀 Features

- User Registration and Login
- Secure Authentication using Sessions
- Blood Donation Campaign Management
- Donor Search by Blood Group
- Admin Dashboard for Management
- Blood Stock Monitoring
- Donation History Tracking
- Responsive User Interface

## 📂 Project Modules

### User Module
- User registration and login
- View active blood donation campaigns
- Donate blood through campaigns

### Admin Module
- Manage donors
- Add and manage campaigns
- Monitor blood stock
- View donation records

### Campaign Module
- Create blood donation campaigns
- Update campaign status
- Manage campaign details

### Blood Stock Module
- Track available blood units
- Automatically update stock after donation

---

## 🗄 Database Tables

The project uses the following main database tables:

- donors
- campaigns
- donations
- blood_stock
- admin

These tables store donor information, campaign details, donation records, and blood stock levels.

---

## 🎯 Project Objective

The main objective of this project is to **automate blood donation management**, reduce manual work, and provide a centralized platform for managing blood donors and campaigns.
